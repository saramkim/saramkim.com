Play Plus는 쿠팡플레이에서 자막을 활용해 외국어를 학습할 수 있도록 만든 Chrome 확장 프로그램입니다.

## 문제

영상으로 언어를 공부할 때는 원문 자막을 확인하고, 놓친 구간을 다시 듣고, 기억할 표현을 따로 모으는 과정이 필요합니다. 하지만 기본 플레이어만으로는 다음과 같은 작업이 번거로웠습니다.

- 영어 자막이 없으면 원문 표현을 확인하기 어렵습니다.
- 자막 위치나 글씨가 학습 방식에 맞지 않으면 영상에 집중하기 어렵습니다.
- 원하는 구간이나 현재 자막을 반복하려면 재생 시간을 직접 조절해야 합니다.
- 지나간 자막을 다시 살펴보거나 기억할 문장을 저장하기 어렵습니다.

## 대상

Play Plus는 쿠팡플레이로 영어를 공부하면서 자막을 따라 듣거나 특정 구간을 반복하고 싶은 사용자를 대상으로 합니다. 자막을 자신의 학습 방식에 맞게 조정하고, 영상 시청과 복습 사이의 번거로운 작업을 줄이는 데 초점을 맞췄습니다.

## 접근

별도의 학습 서비스로 이동하게 하기보다, 사용자가 이미 영상을 보는 쿠팡플레이 안에 학습 도구를 더했습니다. 학습 흐름을 크게 세 부분으로 나누었습니다.

- **이해**: 두 언어의 자막을 함께 보거나 필요한 자막만 선택합니다.
- **반복**: 자막이나 원하는 구간을 기준으로 탐색하고 반복합니다.
- **복습**: 전체 자막을 살펴보고 필요한 문장을 저장합니다.

기본 자막이 없거나 학습에 적합하지 않은 경우에는 사용자가 직접 자막 파일을 등록할 수 있도록 했습니다.

## 핵심 기능

### 이중 자막과 표시 설정

- 영어와 한국어 자막을 동시에 표시하거나 원하는 자막만 선택
- 위치, 색상, 크기, 굵기, 배경 불투명도 조정
- 줄바꿈과 자막 싱크 조절

### 외부 자막 등록

- 사용자가 VTT, SRT, SMI 자막 파일을 직접 등록

### 탐색과 반복

- 시간 또는 자막 단위로 빠르게 탐색
- 단축키로 재생 속도 조절
- 단축키나 마커로 지정한 구간 반복
- 현재 자막 단위 반복
- 자막 저장, 자막 표시 전환, 영상 이동 등의 단축키 사용자 정의

### 자막 탐색과 복습

- 전체 자막을 시간 순서로 표시하고 현재 자막에 맞춰 자동 스크롤
- 자막을 클릭해 해당 시점으로 이동
- 자막 클릭이나 단축키로 문장을 저장하고 Play Plus에서 복습

## 배운 점

영상 학습 도구에서는 기능을 많이 제공하는 것뿐 아니라, 시청 흐름을 끊지 않고 필요한 순간에 바로 사용할 수 있게 만드는 것이 중요했습니다. 또한 자막 표시 방식과 반복 단위처럼 학습자마다 다른 요구는 하나의 고정된 설정보다 사용자가 조절할 수 있는 선택지로 제공해야 했습니다.
